# شهرقالب — نسخه‌های منتشرشده

**شهرقالب** نرم‌افزار مدیریت اجاره و انبار قالب‌های بتنی است: مشتری‌ها، فاکتورها، برگشت‌ها و خسارت‌ها و موجودی انبار، با همگام‌سازی ابری رمزگذاری‌شده بین دستگاه‌ها.

این مخزن فقط برای **دانلود نسخه‌های رسمی** شهرقالب است؛ کد منبع در یک مخزن خصوصی نگه‌داری می‌شود. برنامه‌های شهرقالب به‌روزرسانی‌ها را به‌صورت خودکار از همین‌جا دریافت می‌کنند: فهرست به‌روزرسانی (`latest.json`) همراه امضای دیجیتال (`latest.json.sig`) منتشر می‌شود و برنامه فقط فهرستی را می‌پذیرد که امضایش درست باشد.

# ShahrGhaleb — Official Releases

**ShahrGhaleb** is a management app for concrete-formwork rental businesses: customers, invoices, returns, damage charges and stock, with encrypted cloud sync across devices.

This repository hosts **official release downloads only**; the source code is kept in a private repository. The ShahrGhaleb apps receive their updates from here automatically: the update manifest (`latest.json`) is published together with a digital signature (`latest.json.sig`), and the app only accepts a manifest whose signature verifies.

## Version 1.0.9 — files

| File | Platform |
|---|---|
| `ShahrGhaleb-1.0.9-setup.zip` | Windows — installer (contains `ShahrGhaleb-1.0.9-setup.exe`) |
| `ShahrGhaleb-1.0.9-win64-portable.zip` | Windows — portable build, no installation |
| `ShahrGhaleb-1.0.9-android.apk` | Android — universal build, for all devices |

| `ShahrGhaleb-1.0.9-android-armeabi-v7a.apk` | Android — older 32-bit phones (armeabi-v7a) |
| `ShahrGhaleb-1.0.9-web.zip` | Web (PWA) — runs in the browser |
| `ShahrGhaleb-1.0.9-ios.zip` | iPhone — install from Safari onto the home screen |

If you are not sure which Android file to take, take the universal one (`ShahrGhaleb-1.0.9-android.apk`).
